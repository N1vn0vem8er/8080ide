Guessing game

This is an example of a game where you guess a randomly selected number. First, the maximum value for random number generator and a random number is drawn. This number is stored in register B. Then, in a loop, the character from the keyboard is read and 0x30 is subtracted from it to obtain the actual number. Then, if the entered number matches the one drawn, a winning message is printed and the program terminates. If not, the character from the keyboard is read again.

MVI A,09
OUT 06
IN 06
MOV B,A
loop: IN 00
SUI 30H
CMPB
JNZ loop
LXI H,wonmsg
loopwonmsg: MOV A,M
OUT 01
INX H
CPI 00
JNZ loopwonmsg
HLT
wonmsg: DB 0AH
STRING "You won"
