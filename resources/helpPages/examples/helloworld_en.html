Hello World Example

This is a "Hello World" example that demonstrates using a loop and a string macro. The memory address of the string is loaded into the H and L registers. Inside the loop, the data from that address is moved to the accumulator and displayed. The memory address is then incremented by one for the next iteration.

LXI H,HELLO
MVI B,0A
LOOP: MOV A,M
OUT 01
INR L
DCR B
JNZ LOOP
HLT
HELLO: STRING "hello word"
