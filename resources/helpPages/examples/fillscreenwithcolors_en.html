Fill screen with colors example

This example shows how to fill the screen with all available colors. The screen will be colored using horizontal lines. At the beginning, the cursor is placed at position 0,0xFF, and this position is marked as the start of the line. Next, the cursor moves to position 0xFF,0xFF, which sets the end of the line. Finally, a line is drawn using the color read from register B. In each subsequent iteration, the value in B is decremented. This way, the line is drawn at consecutive positions, each time with a different color.

MVI B,FFH
loop: MOV A,B
OUT 03
MVI A,0
OUT 02
MVI A,1
OUT 05
MOV A,B
OUT 03
MVI A,FFH
OUT 02
MVI A,2
OUT 05
MOV A,B
OUT 04
DCR B
JNZ loop
HLT
